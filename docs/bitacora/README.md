# Bitacora del proyecto

Registro cronologico del desarrollo de MONITOR CIID.

## Proposito

Esta bitacora no es un diario personal. Es el registro tecnico del trabajo
real sobre el proyecto, con evidencia verificable: commits, tests, decisiones
y metricas.

Sirve para:

1. Mostrar evidencia de trabajo real a aliados, instituciones o inversionistas.
2. Recuperar contexto despues de una pausa.
3. Medir velocidad real (no percibida).
4. Construir un caso de estudio con datos.

## Estructura

Cada entrada documenta:

- Fecha y contexto.
- Objetivos de la sesion.
- Commits realizados (con hashes).
- Decisiones tomadas (referencias a ADRs).
- Tests anadidos (antes / despues).
- Estado del proyecto.
- Aprendizajes y obstaculos.
- Siguiente paso.
